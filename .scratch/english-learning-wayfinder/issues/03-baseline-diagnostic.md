## Question

What is the smallest diagnostic that can distinguish the learner's actual starting abilities and error types across comprehension and production, while producing actionable first-cycle evidence instead of a large exam or a misleading CEFR label?

## Answer

The baseline is a compact, progressive, adaptive diagnostic, not a placement exam and not a claim such as "A1". Its output is an initial evidence profile over relevant capability slices from ticket 01, using ticket 02's task-level shape:

`capability/context + mode + support + context novelty + task outcome + error type + delayed/transfer evidence + evidence confidence`.

`unknown / insufficiently probed` is a first-class result. It must not be interpreted as weak ability, and confidence must distinguish absence of evidence from negative evidence. The output also includes prerequisite hypotheses and a recommended first-cycle priority.

Initial coverage should be asymmetric but sufficient for action:

- reading: recognition and comprehension;
- listening: gist, relevant detail, and parsing, progressing from short controlled speech;
- speaking: early sentence production and a short communicative outcome;
- grammar and vocabulary: primarily cross-cutting probes inside meaningful tasks, with targeted probes when a foundational gap is suspected;
- repair: deliberately test recovery from a small communication breakdown;
- pronunciation: intelligibility/comprehensibility within an accessible speaking task;
- writing: one brief probe where useful to the mission, without creating a separate academic branch.

Each probe can progress through `model/example → constrained → independent familiar → changed/novel prompt`. The recorded support level is the help actually required, not merely the nominal task stage: a failed independent attempt followed by a successful hint-supported attempt remains supported evidence, not independent evidence.

The diagnostic stops probing a slice when its boundary is clear enough to select the nearest productive learning zone, when added probes no longer change the working hypothesis, or when an actionable foundational gap has been found. Full profile coverage is not a goal. Learning may start immediately after an actionable gap is found, while unresolved slices are probed incrementally in later sessions.

Results without delayed evidence are explicitly provisional and receive delayed/transfer follow-up in later sessions; no multi-day wait is required before starting useful learning. Self-reported `A1` is stored only as a starting hypothesis. CEFR may later provide an external orientation, but task evidence and prerequisites control material selection.

The diagnostic is low-stakes and learning-compatible. If a short explanation materially clarifies whether a failure is conceptual, linguistic, or task-related, `/teach` may teach briefly and then test a changed prompt. That post-explanation result must remain distinguishable from the initial diagnostic evidence.
