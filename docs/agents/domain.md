# Domain Docs

Engineering skills should read `CONTEXT.md` at the repo root and relevant ADRs in `docs/adr/` before exploring code. Missing files are fine.

This is a single-context repo:

- `CONTEXT.md` — domain glossary and concepts
- `docs/adr/` — architecture decisions

Use terminology from `CONTEXT.md`. Surface any conflict with an existing ADR instead of silently overriding it.
